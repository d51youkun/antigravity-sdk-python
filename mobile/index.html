Google Antigravity SDK は、Antigravity と Gemini を使った AI エージェント開発用 Python SDK です。エージェントの実行基盤を抽象化し、何をするかに集中できます。

インストール GitHub
はじめに

インストール

shpip install google-antigravity
重要: この SDK は PyPI 配布の wheel に含まれるコンパイル済みバイナリが必要です。リポジトリのクローンだけでは動作しません。必ず pip install google-antigravity でインストールしてください。

クイックスタート

API キーを設定して hello_world 例を実行:

shexport GEMINI_API_KEY="your_api_key_here" python ./examples/getting_started/hello_world.py
基本概念

Simple Agent

Agent クラスが最も簡単な入り口です。バイナリ検出、ツール配線、フック登録、ポリシーをまとめて管理します。

pythonimport asyncio from google.antigravity import Agent, LocalAgentConfig async def main(): config = LocalAgentConfig( system_instructions="You are an expert assistant.", ) async with Agent(config) as agent: response = await agent.chat("What files are in the current directory?") print(await response.text()) asyncio.run(main())

ストリーミング

async for でリアルタイムにトークンを受け取れます。

pythonresponse = await agent.chat("Write a short poem.") async for token in response: print(token, end="", flush=True)

Vertex AI / Gemini Enterprise

pythonconfig = LocalAgentConfig( vertex=True, project="your-gcp-project", location="us-central1", ) async with Agent(config) as agent: response = await agent.chat("Hello!") print(await response.text())

事前に gcloud auth application-default login で認証してください。
